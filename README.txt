تحديث عيادات عون — زر لوحة التحكم الخاص بالمسؤول والإشعارات

ما تم تعديله:
- admin-access.js: زر «لوحة التحكم» وزر «خروج المسؤول» لا يظهران إلا عند وجود جلسة Firebase مسجلة دخولًا بالبريد kasemoun4@gmail.com.
- sw.js: تم تحديث رقم نسخة الكاش إلى v13 لمساعدة المتصفح على تحميل نسخة Service Worker الجديدة، مع الحفاظ على ملفات الكتاب ودعم العمل دون إنترنت.
- باقي الملفات والكتب والصور والأخبار ولوحة النشر الأصلية محفوظة كما هي.

طريقة رفع التعديل من الموبايل:
1. افتح مستودع GitHub باسم OUN وخذ نسخة احتياطية قبل أي تعديل.
2. افتح الملف admin-access.js في المستودع، واستبدل محتواه بالكامل بملف admin-access.js الموجود في حزمة الملفات المعدلة.
3. افتح الملف sw.js في المستودع، واستبدل محتواه بالكامل بملف sw.js الموجود في الحزمة.
4. اضغط Commit changes لكل ملف.
5. من Firebase Console تأكد أن تسجيل الدخول بالبريد وكلمة المرور Email/Password مفعّل، وأن حساب kasemoun4@gmail.com موجود وله كلمة مرور معروفة لك.
6. من Firebase Console > Authentication > Settings > Authorized domains تأكد أن kasemoun4-sudo.github.io موجود ضمن النطاقات المسموح بها.
7. لأول تسجيل دخول، افتح صفحة admin.html مباشرة من موقع التطبيق (المسار الذي ينتهي بـ /OUN/admin.html) وسجّل الدخول بالبريد المذكور وكلمة مرور Firebase.
8. ارجع للتطبيق الرئيسي واعمل تحديث للصفحة. سيظهر زر «لوحة التحكم» فقط أثناء تسجيل دخول الحساب الإداري المعتمد. عند الضغط على «خروج المسؤول» سيختفي الزر.

ملاحظات مهمة:
- زر الإشعارات الحالي يطلب الإذن ويستخرج رمز FCM لهذا الجهاز للاختبار فقط. لم يتم بعد حفظ الرموز في قاعدة بيانات أو إعداد إرسال إشعارات تلقائي للمرضى؛ ذلك يحتاج خادمًا موثوقًا مثل Firebase Cloud Functions وقواعد أمان مناسبة.
- لأن الموقع مستضاف كصفحات ثابتة على GitHub Pages، فإن إخفاء الزر والتحقق داخل JavaScript لا يُعد بديلًا عن صلاحيات خادمية كاملة. احتفظ بمفتاح GitHub الشخصي سرّيًا، وقيّد صلاحياته بمستودع OUN فقط، ولا تضعه داخل ملفات HTML أو JavaScript.
- إعدادات Firebase للويب ومفتاح VAPID العام مخصصان للاستخدام في الواجهة. لا ترفع أبدًا مفتاحًا خاصًا لحساب خدمة Firebase.
- لا تستبدل الملفات الأخرى إذا كانت لديك تعديلات أحدث عليها؛ هذا التحديث يحتاج فقط إلى admin-access.js وsw.js.
