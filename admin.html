دخول مسؤول عيادات عون

هذه الصفحة مخصصة للحساب الإداري المعتمد فقط.

بعد التحقق من الحساب، ستظهر لوحة الإدارة الحالية. قد يظل مطلوبًا إدخال مفتاح GitHub والرقم السري الخاصين باللوحة.

لوحة تحكم عيادات عونانشر في التطبيق من موبايلك

أول مرة بس 👋

اللوحة بتنشر في التطبيق مباشرة عن طريق «مفتاح» من حسابك على GitHub. هتعمله مرة واحدة، وبعد كده تدخل برقم سري قصير.

إزاي أعمل المفتاح؟ (دقيقتين)
  1. افتح github.com وادخل على حسابك.
  2. دوس على صورتك فوق ← Settings ← تحت خالص Developer settings.
  3. Personal access tokens ← Fine-grained tokens ← Generate new token.
  4. الاسم: لوحة عون — المدة (Expiration): اختار مدة طويلة، مثلاً سنة.
  5. Repository access: Only select repositories ← اختار OUN.
  6. Permissions ← Contents ← اختار Read and write.
  7. دوس Generate token وانسخ المفتاح (بيبدأ بـ github_pat_) والصقه هنا.
إعدادات متقدمة

🔐 المفتاح بيتحفظ على الموبايل ده بس، ومتشفر بالرقم السري. متبعتش المفتاح لأي حد، ولو الموبايل ضاع امسح المفتاح من GitHub (Settings ← Developer settings).
